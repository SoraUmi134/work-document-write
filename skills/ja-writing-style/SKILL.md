# 日本語の文章のルール（AI っぽさを消す）

## 背景

利用者から「書く文章が AI っぽい」と指摘された。原因は大きく 2 つ。

1. **和語の多用。** 「確かめる」「写し」「起こす」「差し込み」「届く」「流す」のように、技術の話を和語の動詞と名詞で組み立てていた。読みにくく、独特の言い回しに見える。
2. **AI 特有の文型。** 決まり文句、太字ラベル付きの箇条書きの連続、作業の実況、擬人化など。

「和語を避け、熟語とカタカナ語で説明する」と指示すると独特の言い回しが減る、という知見がある。このスキルはその方針を具体化したもの。

## ルール 1: 和語より熟語・カタカナ語

技術の説明では、和語で動作や物を言い換えない。漢語の熟語か、業界で通じるカタカナ語・英語を使う。

| 使わない（和語） | 使う |
|---|---|
| 確かめる・確かめ | 確認する・検証 |
| 試し・試す | テスト・検証・試行 |
| 写し・写す | コピー・複製 |
| 起こす（サブエージェントを） | 起動する |
| 起きる（サブエージェントが） | 起動される |
| 差し込み・差し込む | 挿入（Capability の contributions） |
| 届く（文が） | 反映される・渡る |
| 流す（コマンドを） | 実行する |
| 並べて流す | 並列実行する |
| 直す・直し | 修正する・修正 |
| 足す・書き足す | 追加する・追記する |
| 外す | 削除する・除外する |
| 入れ直す | 再インストールする |
| 作り直す | 再生成する・再作成する |
| 揃える | 統一する・同期する |
| 点検・点検する | レビュー・チェック |
| 読み手（初見の） | レビュアー（前提知識なし） |
| 印・目印 | マーカー |
| 口・差し込める場所 | 挿入ポイント |
| 役（サブエージェントの） | サブエージェント・ロール |
| ゆれ | ばらつき |
| 見込み | 想定 |
| 手当て | 対策 |
| 段取り | 手順・進捗 |
| 控え | バックアップ |
| 決まり | ルール |
| 道（届く道） | 経路 |
| 中身 | 内容 |
| 置き場所 | 配置場所・パス |
| 係 | サブエージェント（名前があれば名前で） |
| 台本 | スクリプト |

- 「する」「ある」「見る」「使う」「書く」のような基本語は、そのまま使ってよい。言い換えるのは、技術の物や動作を表す語。
- 熟語を詰め込みすぎて硬い文にしない。「〜の実施の確認の実行」のような名詞の連結は、動詞の文に戻す。
- 表にない語も同じ考え方で選ぶ。迷ったら「エンジニアが日常の会話で使う言い方」を選ぶ。

## ルール 2: AI 特有の言い回しを使わない

| 避ける | 理由と代わり |
|---|---|
| 「結論から言うと」「まとめると」「ポイントは〜です」 | 前置きは不要。結論の文から書き始める |
| 「〜という形です」「〜となります」「〜となっております」 | 「〜です」「〜します」で言い切る |
| すべての段落を「**ラベル:** 本文」で始める | 太字は 1 画面に数か所まで。見出しで足りる所はラベルを付けない |
| 箇条書きの入れ子が 3 段以上 | 2 段まで。それ以上は文か表にする |
| 「〜ではなく、〜です」の対比の多用 | 言いたい方だけ書く |
| 3 つ並べ（「速く、安く、確実に」） | 実際にある数だけ書く |
| 作業の実況（「〜を確認しました」「〜しておきました」の連続） | 結果だけ書く。何をしたかは必要な所だけ |
| 擬人化・比喩（「黙って無効になる」「顔を出す」「効いている」） | 事実で書く（「警告なしで無効になる」「表示される」「有効」） |
| 「しっかり」「きちんと」「確実に」「大きく」 | 数か具体的な条件に置き換える。無理なら削除 |
| 「〜かもしれません」「〜と思われます」の重ね | 確認済みなら言い切る。未確認なら「未確認」と 1 回だけ書く |
| 「——」（ダッシュ）や「：」で文をつなぐ | 句点で文を切る |
| 「いい質問です」「なるほど」、最後の「ほかに何かあれば」 | 書かない |
| 同じ文末（「〜です。」）が 3 回以上続く | 文を合わせるか、文末を変える |

## 書いた後のチェック

1. 和語の動詞・名詞を拾い、ルール 1 の表で置き換えられないか確認する。
2. ルール 2 の表の語句で検索し、残っていれば書き換える。
3. 置き換えで硬くなりすぎた文は、基本語に戻す。
4. 人に渡す資料は、さらに review-before-delivery のスキルを通す。

## ほかのスキルとの関係

- **chat-reply:** ふだんのチャットの返答のルール（日本語で回答する、結論を先に書く、など）。語の選択はこのスキルを参照する。
- **explain-before-shorten:** 文の組み立て方（伝えたい 1 文 → 口頭で説明する文 → 削る）。このスキルは語の選択と言い回しを担当する。
- **doc-writing:** 資料の構成のルール。そこにある「ふだんの言葉で書く」は「誰でも知っている言葉」の意味で、和語を使えという意味ではない。語の選択はこのスキルに従う。
- **review-before-delivery:** 資料を渡す前のチェック。禁止語の一覧（banned_words.txt）には、無理な和語の技術用語とその置き換えが登録済み。
